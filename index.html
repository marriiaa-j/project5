PROJECT NOTES

Data with a sense of place.

This project uses the United States Geological Survey (USGS) Earthquake Hazards Program API to display real-time earthquake GeoJSON data. Leaflet converts the geographic coordinates into an interactive map.

The circles use a custom pulse animation to make active seismic events easy to notice. Circle size represents magnitude, while color indicates the event’s intensity.
